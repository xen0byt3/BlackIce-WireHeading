    How to use

    • Type like in real Kali. Press Tab to complete, ↑ for history, Ctrl+C to stop.
    • sudo password: kali
    • Phase 7 needs two terminals: click + for a second tab.
    • Pasting several lines works (for the report script).
    • Watch the Kali Desktop and File Manager: folders and files pop in as you create them, and fade or burn when you rm or shred. Double-click items to open them.
    • Created something by mistake? rm file removes a file, rmdir folder removes an empty folder, rm -r folder removes a folder with files inside.
    • Type help for the command list.

    Training sandbox

    Files live in your browser only. Network results (nmap, dig, whois, traceroute and others) are simulated samples, not real scans. Use the real Kali VM when you can.
